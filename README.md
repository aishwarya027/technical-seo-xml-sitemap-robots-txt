
# Technical SEO Project – XML Sitemap & Robots.txt

This project focuses on creating essential **Technical SEO files** for better search engine crawling and indexing of the website [eagletechsolutions.co.uk](https://eagletechsolutions.co.uk).

##  Project Overview
- Designed an **XML Sitemap** containing important pages of the website with details such as:
  - URL
  - Last modification date
  - Change frequency
  - Priority

- Created a **Robots.txt file** to:
  - Restrict crawlers from unnecessary or sensitive pages
  - Guide search engines towards the sitemap
  - Optimize crawl budget and efficiency

## 🚀 Key Learnings
- Improved understanding of **search engine crawling & indexing**
- Hands-on practice with **Technical SEO fundamentals**
- Implementation of **best practices** for sitemap & robots.txt

## 🔗 About the Website
The project was developed for **eagletechsolutions.co.uk**, focusing on improving its technical SEO structure.
